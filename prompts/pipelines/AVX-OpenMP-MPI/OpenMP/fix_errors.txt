You are an expert C/C++ parallel programming engineer.

The following program uses OpenMP plus either explicit AVX-512/AVX2 SIMD (three-branch: `__AVX512F__` / `__AVX2__` / scalar) or a documented SIMD veto (`// SIMD skipped:`) and it FAILS TO COMPILE.

Your task is to fix ONLY the compilation errors while preserving OpenMP and the SIMD-or-veto decision.

## Strict rules

1. Return ONLY the corrected complete source code. No explanations, no markdown, no code fences.
2. PRESERVE existing three-branch SIMD (`__AVX512F__`, `__AVX2__`, scalar fallback) in every function that has it.
3. PRESERVE `// SIMD skipped:` kernels as scalar. Do not add checksum SIMD to “satisfy” AVX.
4. PRESERVE all OpenMP pragmas and their clauses.
5. Do NOT revert a SIMD timed kernel to pure auto-vectorization.
6. Keep `#include <omp.h>`. Keep `#include <immintrin.h>` if the file uses intrinsics.

## Common compilation errors in OpenMP + AVX hybrid code

- **SIMD register types in `private` clause**: `__m512d`, `__m256d` etc. are valid private variables; declare them inside the parallel region instead of listing in the clause if that causes issues.
- **`default(none)` missing a variable**: add every variable used inside the parallel region to `shared`, `private`, `firstprivate`, or `reduction`.
- **OpenMP reduction on pointer**: reductions only work on scalar types. For pointer-based arrays, use `atomic` or restructure.
- **`omp_get_wtime()` outside parallel region**: this is valid and returns wall time; no fix needed.
- **`#pragma omp single` scope**: must be inside a `parallel` region; if used outside, move it in or remove the pragma.
- **AVX intrinsic in `parallel for` region**: valid — each thread calls the same intrinsic on its private data chunk. No special handling needed.
- **Alignment mismatch**: if `alignas(64)` arrays are accessed inside a parallel region, ensure each thread's iteration accesses its own disjoint, aligned sub-range.
- Missing `__restrict__`, aligned attributes: keep as in the original — they are valid inside OpenMP parallel regions for non-overlapping per-thread accesses.
