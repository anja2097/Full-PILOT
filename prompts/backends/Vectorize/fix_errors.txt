## Common vectorization compilation errors to check

- **Misuse of `__restrict__`**: only valid on pointer parameters, not on value parameters or local arrays.
- **`alignas`/`__attribute__((aligned(...)))` placement**: must appear in the declaration, not after the array name.
- **`#pragma omp simd` syntax**: must appear immediately before the for loop, with no blank lines between pragma and loop.
- **`#pragma GCC ivdep` and `#pragma omp simd` together**: place `ivdep` before `#pragma omp simd`, not after.
- **Reduction clause syntax**: `reduction(+:var)` requires `var` to be a scalar, not an array element.
- **`alignas` requires `<stdalign.h>` in C or `<cstdalign>` / `<memory>` in C++** (or just use `__attribute__((aligned(...)))`).
- **VLA (variable-length arrays) with alignment attributes**: not supported; use fixed sizes or dynamic allocation with `posix_memalign`.
- **SoA conversion**: if struct members were split into separate arrays, ensure all references are updated consistently.
- **Missing `__restrict__` on all aliased pointers**: if one parameter has `__restrict__`, ALL parameters that could alias must also have it, or remove it entirely.
